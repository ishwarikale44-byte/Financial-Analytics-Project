\# Financial Analytics Project



\## 📊 Overview



This project analyzes personal financial transaction data using Python, SQL, Excel, and data visualization techniques.



The project provides insights into income, expenses, savings, spending categories, and monthly cash flow.



\## 🎯 Objectives



\- Analyze income and expenses

\- Calculate total savings

\- Identify high-spending categories

\- Analyze monthly expenses

\- Perform SQL-based financial analysis

\- Create an Excel dashboard

\- Visualize financial trends



\## 🛠️ Technologies Used



\- Python

\- Pandas

\- Matplotlib

\- SQL

\- SQLite

\- Microsoft Excel

\- Git \& GitHub
